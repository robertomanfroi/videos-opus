# Story 1.2 — Edição viral e vídeos animados no pacote portátil

**Status:** InReview
**Épico:** Skill videos-opus para alunas leigas (pacote único, instala uma vez)
**Data:** 2026-10-15
**Depende de:** 1.1

## Contexto

A edição viral feita à mão para a Super Black Eterna (15/10) usava Python, PIL, numpy e Playwright com
Chromium baixado. A `videos-opus` original gravava animações com `gravar.py` (Python + Playwright) e buscava
o acervo com `buscar.py`. Nada disso existe na máquina da aluna. Esta story leva os três para o Node portátil,
usando o Microsoft Edge que já vem no Windows.

## Critérios de aceite

1. [x] `animar <html>` grava HTML → MP4 quadro a quadro pelo Edge (playwright-core 1.63.0, sem baixar navegador).
2. [x] `fotos <html> --em ...` tira fotos de instantes para conferir antes de gravar.
3. [x] `acervo` busca e mostra prompts do acervo (porte do `buscar.py`).
4. [x] `viral <pasta>` faz a edição viral num encode só: abertura com título explodindo (sobre o trecho mudo
       do começo, quando há), zoom e tremor (expressões do FFmpeg), legenda comum (libass) fora das frases-chave,
       frases-chave gigantes, botão de chamada, selo, efeitos sonoros e batida sintetizados em Node.
5. [x] `cortar --manter-inicio` guarda o trecho mudo do começo; `transcrever` pula o silêncio inicial (o whisper
       errava o tempo das palavras quando o áudio começava mudo).
6. [x] `diagnostico` testa também o navegador.
7. [x] Exemplo de animação autocontido (`exemplos/oferta-animada.html`, fontes locais).
8. [x] Teste pelo zip instalado com `Expand-Archive`.

## Resultado do teste (15/10/2026, Windows do Roberto, pelo zip instalado)

- Diagnóstico: navegador, ffmpeg, ffprobe, whisper, 5 fontes, encoder h264_qsv: tudo ok.
- `animar` do exemplo (10 s): 16 s de gravação. Captura pela CDP: JPEG 95 ms/quadro (PNG pelo Playwright
  levava 432 ms), PNG transparente rápido 148 ms/quadro.
- `viral` no `IMG_4150.MOV`: preparar + cortar --manter-inicio + transcrever + viral = 99 s para 21,4 s de vídeo;
  abertura de 5,2 s sobre o trecho mudo, 2 frases-chave, CTA, selo, áudio em -12,5 LUFS.
- Zip: 305 MB.
