# Story 1.3 — Os 5 estilos da Edição Automática no pacote portátil

**Status:** InReview
**Épico:** Skill videos-opus para alunas leigas (pacote único, instala uma vez)
**Data:** 2026-10-15
**Depende de:** 1.1, 1.2

## Contexto

A Edição Automática (`/home/roberto/edicao-automatica`, commit 64ed5eb) tem 5 estilos completos (celular, editorial,
explicativo, colagem, anúncio) sobre o HyperFrames, mas exige um instalador que baixa uns 3 GB (Node, Git, Python,
FFmpeg, LocalSend, modelos) e um ambiente Python (faster-whisper, numpy, onnxruntime).

Decisão: levar o kit inteiro dentro da skill, já compilado para Windows (cópia do `C:\EdicaoAutomatica\node_modules`
instalado e testado em 13/10), trocar todo o Python por Node e rodar tudo pelo lançador `video.mjs kit`.

## Critérios de aceite

1. [x] HyperFrames renderiza com o **Edge do Windows** (`HYPERFRAMES_BROWSER_PATH`) e o FFmpeg portátil
       (`HYPERFRAMES_FFMPEG_PATH`), sem baixar o chrome-headless-shell. Log: `Browser launched (Edg/155…)`.
2. [x] Lançador `kit [--em subpasta] node|hyperframes|ffmpeg|ffprobe …` com pasta de trabalho em
       `%LOCALAPPDATA%\videos-opus\kit` (junções para o código da skill; projetos, prontos e perfil ficam fora da skill).
3. [x] Python trocado por Node: `transcrever.mjs` (whisper.cpp + VAD Silero, mesma interface e JSON, `--janelas`,
       `--nomes`, `--txt/--srt`), `corte-preciso.mjs`, `matte-pessoa.mjs`, `recortar.mjs` (onnxruntime-node, DirectML/CPU),
       `remapear-tempos.mjs` (LCS no lugar do difflib), `achar-fotos.mjs` (fetch).
4. [x] `npx hyperframes` → `node …/hyperframes/dist/cli.js` no `renderizar.mjs`; `-filter_complex_script` → `-/filter_complex`.
5. [x] Guias (`editar` + 5 estilos + perfil) reescritos para o lançador `$K`, sem LocalSend, instalador, `$PY` nem `npx`.
6. [x] Entrega também em **Vídeos editados** na Área de Trabalho (`prontos.mjs`).
7. [x] Os 5 estilos rodam de ponta a ponta no Windows e renderizam (teste com `IMG_4150.MOV`).
8. [x] `diagnostico` confere o kit; zip instalado do zero passa.
9. [x] Instalação por `tar -xf` (6 s) no lugar do `Expand-Archive` (43 min com 7.500 arquivos).
