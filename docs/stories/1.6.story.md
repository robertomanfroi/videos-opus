# Story 1.6 — Vídeos Opus no Mac (Claude e Codex)

**Status:** InProgress
**Épico:** Skill videos-opus para alunas leigas (pacote único, instala uma vez)
**Data:** 2026-10-19
**Origem:** pedido do Roberto — alunas de Mac não conseguem usar a skill (o card da MIRA diz "só Windows").

## Contexto

O pacote leva os programas dentro (FFmpeg, Node, whisper.cpp, kit de estilos com node_modules nativos), todos
compilados para Windows, e os instaladores são `.cmd`. O código dos scripts já tem caminhos de reserva fora do
Windows; o que falta é: binários de macOS, navegador (Chrome no lugar do Edge), aceleração da Apple, instalador
por Terminal e os textos do SKILL.md.

Decisões (Roberto, 2026-10-19): versão **completa** (tudo o que o Windows faz) e instalador para **Claude e Codex**.
Sem Mac físico: compilação e teste de ponta a ponta nos runners macOS do GitHub Actions (repo público).
Instalação pelo Terminal (`curl … | bash`): arquivo baixado pelo curl não recebe a marca de quarentena, então o
Gatekeeper não barra e não precisa de conta Apple Developer.

## Critérios de aceite

1. [x] Scripts portáteis: navegador no Mac (Chrome, Edge, Brave, Chromium; sem nenhum, baixa o Chrome headless
       na instalação), pastas de dados no Mac, `h264_videotoolbox`, CoreML no recorte de pessoa, `open` no lugar
       do PowerShell. Windows segue igual (testes e diagnóstico verdes no Windows).
2. [x] SKILL.md (Claude e Codex) e skills do kit dizem como rodar o Node no Mac.
3. [ ] Binários de Mac (Apple Silicon e Intel) gerados no GitHub Actions: node, ffmpeg/ffprobe, whisper-cli e
       node_modules do kit.
4. [ ] `empacotar.sh` gera `videos-opus-mac-arm64.zip` e `videos-opus-mac-x64.zip`.
5. [ ] `instalar-mac.sh` e `instalar-mac-codex.sh`: detectam o chip, conferem espaço, baixam, trocam a versão com
       segurança e rodam o diagnóstico.
6. [ ] Teste de ponta a ponta nos Macs do GitHub (arm64 e Intel), instalando pelo instalador: diagnóstico, corte +
       legenda, edição viral, vídeo animado e um estilo do kit.
7. [ ] Release publicada com os zips de Mac e os instaladores; README, guia e card da MIRA com o passo do Mac.
